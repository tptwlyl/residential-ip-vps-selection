## 先把四个概念分清：为什么便宜的机房 IP 用不了

普通 VPS 的 IP，ASN 归属是数据中心运营商。平台查一次就知道“这不是普通本地家庭用户”，于是 TikTok 账号地区乱跳、Netflix 提示内容不可用、DMM TV 直接地区限制、注册 ChatGPT 被风控。住宅 IP 的 ASN 归属是真实的本地宽带运营商，IP 属性被标记为住宅/家宽，从风控视角看和住在当地、用着本地宽带的普通用户没有区别。你为住宅 IP 付的钱，本质上买的是这个“被当作本地人”的判定结果。

围绕这个词有四个概念经常被混着用，实际指向完全不同：

| 概念 | 指的是什么 | 常见误解 |
| --- | --- | --- |
| 住宅 IP | IP 的 ASN 归属是真实本地宽带运营商，被标记为住宅/家宽 | 以为“IP 在本地”就是住宅 IP |
| 原生 IP | IP 的注册地与服务器实际所在地一致，不是异地广播过来的 | 以为原生 IP 就等于住宅 IP |
| 双 ISP | 一个 IP 同时被两家 ISP 登记为家庭宽带用户 IP，可信度高于单 ISP | 以为双 ISP 是“两条线路” |
| 家宽 VDS | 整台机器托管在真实民房住宅，走当地家庭宽带线路 | 以为和机房里的“住宅属性 IP”是同一档 |

原生 IP 和住宅 IP 不是一回事，这一点最容易花冤枉钱。以 DMIT 为例，它提供的是原生 IP：注册地和机房地点一致，比数据中心广播 IP 干净，在平台眼里更接近真实本地 IP，解锁流媒体、搭节点都够用。但它仍然是机房 IP，不等于严格意义上的家庭宽带住宅 IP。如果你只是要看 Netflix、搭个代理，原生 IP 足够；如果要做几十上百个账号的矩阵，需要的是真正的家庭宽带 IP 池，那是另一个产品类别。这里只做区分，不存在谁更好的问题，取决于你要干什么。

“静态”这个词也要留意。静态意味着这个 IP 固定属于你，不像动态住宅代理那样频繁轮换。账号运营最怕的就是今天登录在东京、明天跳到另一个城市，静态是账号身份稳定的前提。

## 限制、退款规则，以及哪些人不该买

**退款政策按产品线分成三档，不是统一的。**9929、4837、纽约、芝加哥这几条线支持 48 小时内不满意无条件退款。家宽 VDS 全系列（西雅图、加州 Astound、T-Mobile/Frontier）和日本住宅 IP 类标注为特殊产品，只退网站余额，不回原支付账户。NAT 共享版标注无退款。IP 属于资源性产品，退款条件比普通 VPS 严格，下单前建议先和客服确认清楚自己那条线适用哪一档。

**带宽峰值不等于持续带宽。**NAT 共享版明确写的是 CN2 GIA 峰值，并且禁止长时间占用，意思是能短时冲到标称值，但不能一直跑。家宽 VDS 用的是真实家庭宽带带宽，相对更可持续。9929 / 4837 是机房带宽，峰值能跑满，但受月流量配额约束。

**流量统计口径有三种，不能混着算。**家宽 VDS 的流量版是单向统计月流量，NAT 共享版是双向统计，9929 / 4837 是月流量配额。买之前按自己业务的月消耗估一遍，别等跑完才发现口径不对。

**日美两条住宅线都不是大陆直连优化线路。**官方建议通过香港或日本线路中转落地，部分地区移动和电信直连效果尚可。稳妥做法是中转加开启 BBR 加速。指望买回来直连就跟本地机房一样快，会失望。

**部分高价位档位对个人用户没有意义。**9929 豪华版 899 元/月只给 100Mbps，日本不限流量 Pro 1899 元/月，这些档位是给真正需要 4核4G 跑实际业务的团队准备的。个人养号、看流媒体，买这些纯属浪费。

**下单前先测 IP。**丽萨支持工单索要测试 IP。拿到后用 ipinfo.io 查归属是否为真实住宅 ISP，用 scamalytics 查风险分（越低越好），必要时用平台自带的 IP 检测工具看是否被识别为住宅段。这一步省不了，否则买回来可能发现整个 IP 段已经被滥用过。

**客服渠道是在线工单和在线客服**，中文沟通，第三方测评对售后响应的评价整体偏正面，好评集中在 IP 纯净度和线路稳定性。Trustpilot 上有评分但样本量很小，参考价值有限。

## 几个高频疑问

**住宅 IP 和原生 IP 到底差在哪？**原生 IP 说的是注册地和服务器所在地一致，解决的是“IP 归属别乱标”的问题；住宅 IP 说的是 ASN 归属为家庭宽带运营商，解决的是“平台把你当本地用户”的问题。原生 IP 可能仍然是机房 IP。看流媒体、搭节点，原生 IP 够用；做账号矩阵，需要的是住宅 IP。

**买了日本 VPS，为什么 DMM TV 还是提示地区限制？**因为限制依据的是 IP 的 ASN 归属和风控评分，不是服务器物理位置。机房 IP 即使标着东京，平台一查 ASN 就知道不是家庭用户。这种情况要换 IIJ 双 ISP 那条线，而不是换更贵的机房套餐。

**共享 NAT 能不能用来养号？**不能。共享 IP 上任何一个人违规，整段 IP 的风险分会上升，你的账号会被一起牵连。养号必须独享 IP。NAT 共享版适合的是只需端口转发的固定出口场景。

**年付能不能退款？**9929 / 4837 / 纽约 / 芝加哥在 48 小时内可以无条件退款；家宽 VDS 和日本住宅 IP 类只退网站余额；NAT 共享版无退款。这也是建议先月付试 IP 的原因：月付试错成本低，年付虽然叠加后只要 7.2 折，但退起来麻烦。

**流量用超了会怎样？**不同产品线处理方式不同，官方页面没有统一说明。下单前直接问客服，比事后猜要省事。
